# 🔍 VeriLens AI

### See beyond what looks real.

VeriLens AI is an AI-powered credibility assistant designed to help users evaluate suspicious digital content before trusting or sharing it.

It analyzes text, claims, and images using multimodal AI and provides an explainable credibility assessment rather than simply labeling content as “real” or “fake.”

## ✨ Features

- Analyze suspicious text and online claims
- Analyze uploaded images using multimodal AI
- Generate an advisory credibility score
- Identify potential warning signs and credibility signals
- Explain source and context concerns
- Highlight missing evidence or information
- Recommend practical verification steps

## 🧠 How It Works

1. The user submits text, an image, or both.
2. VeriLens sends the content to a multimodal AI model for analysis.
3. The system evaluates credibility signals, context, and potential red flags.
4. VeriLens generates an explainable assessment including:
   - Credibility Score
   - Risk Status
   - Key Signals
   - Claim Credibility
   - Source & Context
   - Manipulation / Red Flags
   - Supporting Evidence
   - Missing Information
   - Recommended Verification Steps

## 🛠 Built With

- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK
- Pillow

## ⚠️ Important Note

VeriLens is an AI-assisted credibility analysis tool, not an authoritative fact-checking service. Its credibility score is an advisory heuristic and should not be interpreted as a statistical probability or definitive determination of whether content is real or fake.

Human verification still matters.
